# استعادة — مصادر التحقق العلمي النهائي

**المرحلة 3 — Evidence Sources.** كل مصدر هنا استُخدم فعليًا في إصدار الأحكام أعلاه.
لم يُدرج أي DOI أو رابط إلا إذا ظهر أو تأكد في نتائج البحث الفعلي أو في التوثيق
الببليوغرافي القياسي المتحقق منه. نتائج البحث الخام محفوظة في
`scripts/evidence-search/` (24 ملف JSON) للمراجعة.

**ملاحظة عن الروابط:** محرك البحث المستخدم يعيد عناوين النطاقات على مستوى الجذر؛
لذلك يُذكر «الوصول» بنطاق المصدر (مثل PMC / JAMA Network / Wiley) بدل رابط عميق
غير متحقق منه، وتُذكر معرفات DOI/PMID حيث تأكدت حرفيًا.
